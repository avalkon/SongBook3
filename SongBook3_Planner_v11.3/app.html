Folder explorer

Choose instruments ▾

Generic aliases such as Flute and Drum normalize to Basic Flute and Basic Drum. Edit 'instrument-aliases.csv' to add aliases. Part counts are preserved independently.

Band members

Choose the available players and their playable instruments, grouped by family. Only Lotro instruments appear, edit the aliases file to add more based on your own abc files. Assignment optimization minimizes per-player instrument changes between songs.

Specialists are prioritized for Lonely Mountain Fiddle/Bassoon, Bardic Fiddle, Sprightly Fiddle, Traveller's Trusty Fiddle and Brusque Bassoon. Basic Fiddle/Bassoon can also use their Lonely Mountain sound when the same player uses it in an adjacent song. Lock any chosen assignment before rebalancing another part.

Set an instrument's checkbox to indicate that player can perform it. Changing the member count preserves existing names and skills where possible.

Instrument-part capacity

Set the maximum simultaneous parts for each instrument. Zero means unavailable. Save a profile for different band lineups.

Settings & corrections

Edit a song's track assignments using its “Parts” panel. Player lists, profiles, setlists, and corrections are saved as JSON in the local settings/ folder. This browser also keeps a recovery copy.

Song library

Browse folders like a file explorer. Search descends through the selected folder but never searches its parent.

Part counts use the original SongBook track count, including tracks without recognized instruments.

Setlist

Drag songs or use ↑ ↓ to reorder. Changes are calculated between adjacent songs.

Named setlists are saved in settings/saved-setlists.json. Working edits auto-save separately; use Save setlist to update the named version.

Specialty parts take priority when there aren't enough players. Use “Lock” to protect a chosen player and instrument from future rebalances. Basic Fiddle / Bassoon can be played on their Lonely Mountain counterparts only when that player uses the same specialty in an adjacent song.
